# Save the Aravallis — Public Awareness & Conservation Platform

Welcome to the digital campaign repository for **Save the Aravallis**. This project hosts an open-access web platform built using clean HTML5 to raise urgent public awareness about the ecological crisis facing the **Aravalli Range**—one of the oldest fold mountain systems on Earth.

Our primary goal is to provide a clean, accessible web landing page that highlights the impact of illegal mining, rapid urbanization, and deforestation across Haryana, Rajasthan, and the Delhi-NCR landscape.

---

## 🌿 Why the Aravallis Matter
The Aravalli hills provide irreplaceable ecological infrastructure to North-West India:
* **Climate Buffer:** Acts as a natural barrier checking the eastward spread of the Thar Desert.
* **Water Security:** Serves as a vital groundwater recharge zone for major urban cities like Gurugram, South Delhi, and Faridabad.
* **Air Quality & Wildlife:** Functions as a critical green lung to absorb carbon emissions and supports sensitive biodiversity hotspots.

## 💻 Local Installation & Setup
Since this platform runs entirely on standard web clients, you can launch it locally without installing complex database configurations or background servers.

1. Clone or download this repository to your local directory:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the root folder.
3. Open the `index.html` file directly inside any modern web browser (such as Google Chrome, Firefox, or Safari).
